# Evaluated Frame State

`EvaluatedFrameState`: immutable frame identity/provenance; timing; resolved scene/world; entities with transforms/visibility/assets/materials; resolved 2D layer/deformer/sprite/cel state; resolved 3D mesh/skeleton/morph state; character pose/facial states; cameras/active camera; lights; audio synchronization state; render intent; diagnostics. It is renderer input and contains no mutable timeline semantics.
