# Procedural Scene Generation Evaluation

## Minimum viable “Create a classroom”

1. Resolve a reusable classroom scene template and style profile from available approved assets.
2. Instantiate canonical 2D/3D/hybrid Scene entity graph.
3. Apply parameterized dimensions, background, lighting/camera defaults and render layers.
4. Place required props—desks, blackboard, teacher table, windows—using template anchors/grid zones and collision/spacing rules.
5. Produce navigation anchors such as door, teacher position and student standing areas.
6. Validate assets/capabilities and disclose defaults/missing assets.

Build ourselves: template contract, grid/layout constraints, relational placement, anchors, navigation zones, lighting/camera presets and deterministic seeds. Do not claim arbitrary professional environment generation; quality remains bounded by templates/assets. Local/external generation is an optional adapter for candidate assets only.
