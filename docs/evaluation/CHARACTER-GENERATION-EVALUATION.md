# Procedural Character Generation Evaluation

## Realistic non-AI scope

Build ourselves: parameter schemas, deterministic seeds, template selection, body/face parameter application, semantic slot resolution, 2D layer assembly, wardrobe/accessory attachment, palette/material overrides, compatible rig binding, variants and provenance. These are asset assembly and constrained procedural generation, not unrestricted character-art generation.

For 2D, start with artist-authored layers/templates and compatible skeletal/mesh/cel modules. For 3D, start with authored compatible base meshes, materials/morph parameters, rig profiles and attachable outfits. Hair, face and clothing choices require an approved reusable asset library. A seed chooses documented options/parameters; it cannot create un-authored professional assets.

AI/local/external generation remains an optional GenerationAdapter and must produce quarantined, provenance-recorded candidates before asset acceptance. No character generator is recommended for Phase 1.
