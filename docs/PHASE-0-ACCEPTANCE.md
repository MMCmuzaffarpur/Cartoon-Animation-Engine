# Phase 0 Acceptance

Phase 0 is complete only when master architecture and all required ADRs are documented; every requested schema has a normative specification and cross-reference; API, prompt/command, generation and capability contracts are defined; determinism, security, licensing and provenance policies exist; repository boundaries and test strategy are documented; evaluation plans exist; and unresolved risks/decisions are explicit.

Completion does not approve any production implementation, dependency installation, server, renderer, UI, generator, or Phase 1 work. Architectural changes discovered during evaluation require a proposal ADR with problem, alternatives, consequences and explicit approval before adoption.
