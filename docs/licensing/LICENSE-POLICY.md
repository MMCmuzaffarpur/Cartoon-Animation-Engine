# License Policy

Phase 0 approves no dependency, model, asset, codec, backend, or build configuration. Future adoption requires recorded review.

Preferred software licenses are MIT, BSD, Apache-2.0, ISC and zlib/libpng. MPL and LGPL require distribution/linking review. GPL tools (including possible external-process adapters) require specific distribution review. AGPL, SSPL/source-available, non-commercial, no-derivatives or unclear licenses are prohibited for the core unless an approved ADR and legal review explicitly change policy.

Every dependency category—runtime library, renderer, codec, importer, tool, model code, model weights, font, texture, audio, character base and generated asset—must record license requirement, source location/hash, attribution/notice, modification obligations, model-weight terms, redistribution obligations, transitive dependencies and review status. Public availability is not approval.
