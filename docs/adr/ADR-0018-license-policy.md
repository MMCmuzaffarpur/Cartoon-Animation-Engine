# ADR-0018: License policy
Status: Accepted

## Context
Dependencies, models and assets have distinct legal obligations.
## Decision
Review and record each before adoption; prefer permissive licenses; prohibit unreviewed core dependencies and source-available/non-commercial terms.
## Alternatives considered
Ad hoc dependency adoption; public-source-only assumption.
## Consequences
Release requires notices, SBOM and redistribution review.
## Open risks
No specific dependency is approved in Phase 0.
