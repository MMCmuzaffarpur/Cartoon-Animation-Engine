# ADR-0007: Canonical 3D and glTF boundary
Status: Accepted

## Context
3D projects require an open interchange format without tool ownership.
## Decision
Use engine-owned canonical 3D scenes and glTF 2.0 as initial import/export interchange.
## Alternatives considered
Blender-native canonical data; proprietary formats; USD-first core.
## Consequences
Normalization and compatibility diagnostics are required.
## Open risks
Detailed glTF feature subset and USD future scope need evaluation.
